# Iteration 10: Integrated Interview Preparation Workflow

## Outcome

A user can select a preparation target and move from catalog coverage through pattern learning, transfer, and external implementation evidence.

## Scope

- Add a preparation workspace scoped by source list, company filters, or a custom selection.
- Prioritize uncovered foundations, weak reasoning evidence, failed transfer, and stale implementation evidence.
- Keep company frequency and recency as dated overlays and tiebreakers.
- Provide clear next actions: Learn pattern, Review reasoning, Try transfer, or Implement externally.
- Show coverage and evidence by pattern without a single readiness score.
- Add an end-to-end onboarding path using a small redistributable sample catalog and lesson.
- Reconcile terminology, navigation, documentation, backup, and accessibility across all prior iterations.

## Prove it

- Exercise a complete disposable-library journey from catalog import to checkpoint record.
- Verify priorities are deterministic, explainable, and never based on unsupported probability claims.
- Conduct browser, accessibility, package-artifact, migration, and regression testing across the full workflow.
- Refine the workflow after representative user testing before calling the iteration complete.

## Excluded

- Accounts, social features, runtime AI, mock-interview scoring, global readiness percentages, or proprietary content bundles.
