# Iteration 06: Interview Preparation Workflow

## Outcome

A user can move from referenced problems through pattern reasoning, spaced review, and external implementation prompts using existing primitives.

## Scope

- Add an interview-prep view over Sets, Cards, Tags, source links, and session evidence.
- Filter by source list, company label, pattern tag, or custom selection.
- Offer clear next actions: Learn lesson, Review due, Try transfer, or Implement externally.
- Prioritize uncovered lessons, weak reasoning cards, and failed transfer using explainable existing data.
- Treat dated company/list metadata as filters and tiebreakers, never probability claims.
- Add onboarding with the redistributable sample lesson from Iteration 05.
- Reconcile terminology, navigation, backup/export, and accessibility across all iterations.

## Prove it

- Exercise a disposable-library journey from sample install to review and external handoff.
- Verify deterministic explanations for each recommended next action.
- Run browser, accessibility, package-artifact, migration, and full regression gates.
- Refine the workflow after representative user testing before completion.

## Excluded

- New learning entities, implementation ledger, code runner, mock score, readiness percentage, accounts, sync, and runtime AI.
