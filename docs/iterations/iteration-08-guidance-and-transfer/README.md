# Iteration 08: Faded Guidance and Transfer Practice

## Outcome

Pattern lessons can move from supported comprehension to independent recognition without memorizing problem titles.

## Scope

- Extend authoring metadata to identify worked example, completion, reconstruction, discrimination, and transfer stages.
- Support completion tasks with progressively less of the plan supplied.
- Hide pattern labels and source provenance until commitment on transfer activities.
- Allow near-miss and competing-approach explanations with deterministic feedback where possible.
- Preserve multiple valid approaches and explain which constraints favor each.
- Update lesson validation and authoring guidance for variation, subgoals, leakage, and exact-order Parsons limits.
- Add a research-grounded sample pattern lesson using redistributable original prompts.

## Prove it

- Validate stage ordering without making authoring guidance an unnecessary hard gate.
- Test hidden-label reveal, retry behavior, export/import, and accessibility.
- Run browser studies with the sample lesson and check that source titles do not cue answers.

## Excluded

- Runtime model grading, copied LeetCode statements, or one lesson per named problem.
